A Wiki for My DWM Dotfiles

Welcome to the wiki for my DWM dotfiles! 🚀
Note: This wiki might not have everything 100% accurate. For the full setup, including all the code, follow the instructions below.
How to Access the Full Wiki

Clone My Dotfiles / Dwm 


```bash git clone https://github.com/ahmadjerjawi/Dwm-Dotfiles  
cd Dwm-Dotfiles/local/src/dwm-flexipatch/wiki.page
```
Open the wiki file included in the repository.

Run the following commands to preview it locally:

```bash
    npm install  
    npm run preview  
```
That’s it! You’ll have the full wiki and setup ready to explore.
